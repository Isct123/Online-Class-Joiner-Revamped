# Online-Class-Joiner
The longest step in doing an activity is starting one. The online class joiner makes it easier to join your online classes. This is marketed as a chrome extension, but you can also use it as a website if you ignore the "manifest.json". <br></br>
The file "data.json" is like the database where you can add or remove subjects and links. To join your class, simply click the button that has the subject. <br></br>
Additionally, you can also embed files such as your timetable with ease.
